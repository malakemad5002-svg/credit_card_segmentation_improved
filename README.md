# Credit Card Customer Segmentation

## Project Overview
This project applies Machine Learning clustering techniques to segment credit card customers based on their financial behavior and spending patterns.

## Objectives
- Analyze customer behavior
- Perform data preprocessing
- Apply clustering algorithms
- Visualize customer segments
- Improve customer targeting and business insights

## Algorithms Used
- K-Means Clustering
- Agglomerative Clustering
- Autoencoder-based Clustering
- IDEC / Deep Clustering Techniques

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / PyTorch
- Matplotlib
- Streamlit

## Files Included
- Jupyter Notebook implementation
- Data preprocessing steps
- Clustering models
- Evaluation results
- Visualization outputs

## How to Run
1. Install required libraries
2. Open the notebook
3. Run all cells sequentially
